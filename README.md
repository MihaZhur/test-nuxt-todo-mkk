# Notes

SPA-приложение для заметок с todo-списками на Nuxt 4, Composition API, TypeScript и Pinia.

## Возможности

- создание, редактирование и удаление заметок;
- добавление, редактирование, удаление и выполнение todo-пунктов;
- ручная история undo/redo до 50 операций без полных снимков заметки;
- объединение непрерывного ввода в одну операцию истории;
- версионированное хранение заметок в `localStorage`;
- отложенное сохранение и восстановление несохранённого черновика;
- синхронизация сохранённых данных между вкладками;
- доступные модальные окна с focus trap и управлением клавиатурой;
- адаптивный интерфейс без UI-библиотек.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Проверки

```bash
npm run typecheck
npm test
npm run build
```

## Docker

```bash
docker compose up --build
```

Контейнер публикует приложение на `http://localhost:3000`.

## Структура

- `app/pages` — две страницы приложения;
- `app/components/notes` — компоненты предметной области;
- `app/shared/ui` — переиспользуемые элементы интерфейса;
- `app/shared/lib` — история, хранилище и общие функции;
- `app/composables` — логика сессии редактирования;
- `app/stores` — Pinia-store заметок;
- `tests` — unit-тесты истории и стора.
